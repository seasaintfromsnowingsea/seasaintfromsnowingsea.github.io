반복되는 엔지니어링 해석과 업무를 소프트웨어로 자동화합니다

쿠키인터랙티브는 구조해석(FEA) 자동화와 업무 자동화, 맞춤형 소프트웨어 개발을 하는 회사입니다. 설계와 해석 업무에 맞춘 소프트웨어로 작업 시간과 비용을 줄입니다.

솔루션

사람이 손으로 되풀이하던 해석과 업무를 소프트웨어가 처리하도록 만듭니다.

엔지니어링 해석 자동화

3D 모델 생성부터 유한요소해석, 보고서 작성까지 이어지는 작업을 하나의 흐름으로 자동화합니다. 하중조합을 하나씩 돌리고 결과를 손으로 옮기던 일을 줄입니다.

업무 자동화

엑셀, 문서, 웹 시스템을 오가는 반복 업무를 Python 기반 자동화(RPA)로 바꿉니다.

맞춤형 소프트웨어 개발

사내 시스템, 데이터 파이프라인, 업무 도구를 요구사항에 맞춰 개발하고 공급합니다.

시스템 통합과 컨설팅

컴퓨터시스템 통합에 관한 자문과 구축, 소프트웨어 개발과 자동화에 관한 교육·컨설팅을 제공합니다.

개발 중

자체 제품 Q-Flow

API 661 공랭식 열교환기(ACHE) 헤더박스의 구조해석을 형상 입력부터 보고서까지 자동화하는 엔지니어링 소프트웨어입니다.

Q-Flow 자세히 보기

  1. 3D 모델링

    헤더박스와 노즐의 치수를 입력받아 해석용 3D 형상을 만듭니다.

  2. 유한요소해석

    해석 입력 파일을 만들고 솔버를 실행해 하중조합을 모두 계산합니다.

  3. 보고서 생성

    해석 결과를 표준 양식의 보고서로 정리합니다.

설계와 해석을 아는 소프트웨어 회사

요구사항을 엔지니어의 언어로 듣고 소프트웨어로 옮깁니다.

엔지니어링 실무에서 출발합니다

3D CAD 모델링과 구조해석(FEA)의 절차, 판정 기준, 보고서 양식에 맞춰 소프트웨어를 설계합니다. 결과물이 엔지니어의 검토 과정에 그대로 쓰이도록 만듭니다.

Python으로 처음부터 끝까지 연결합니다

모델 생성, 해석 실행, 결과 정리, 문서 작성을 Python으로 이어 붙여 사람이 개입하는 단계를 줄입니다.

대기업 현장에서 수행했습니다

2023년부터 국내 대기업(전자 제조) 현장에서 소프트웨어 개발 프로젝트를 수행해 왔습니다.
