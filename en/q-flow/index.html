Q-Flow

Engineering software that automates the structural analysis of API 661 air-cooled heat exchanger (ACHE) header boxes, from geometry input to report.

Ask about the product

From manual analysis steps to a single flow

Q-Flow replaces the work of refining meshes and running load combinations one at a time with an automated procedure. Load combinations that are easy to skip because of time and cost are all calculated by the same procedure.

  1. 3D modeling

    Takes the header box and nozzle geometry as input and automatically builds the 3D geometry for analysis.

  2. Finite element analysis

    Generates analysis input files in Python, runs them on the CalculiX solver, and calculates every load combination.

  3. Report generation

    Writes an analysis report in a standard format, including SCL (stress classification line) results.

Eight default load combinations

By default Q-Flow calculates eight combinations of maximum allowable working pressure (MAWP) with wind and seismic loads in each direction.

LoadDirection
MAWP + wind+X, −X, +Y, −Y
MAWP + seismic+X, −X, +Y, −Y
