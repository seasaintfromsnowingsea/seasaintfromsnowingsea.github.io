In development

Our product: Q-Flow

Engineering software that automates the structural analysis of API 661 air-cooled heat exchanger (ACHE) header boxes, from geometry input to report.

More about Q-Flow

  1. 3D modeling

    Takes header box and nozzle dimensions and builds the 3D geometry for analysis.

  2. Finite element analysis

    Generates the analysis input files, runs the solver, and calculates every load combination.

  3. Report generation

    Puts the analysis results into a report in a standard format.
