개발 중

Q-Flow

API 661 공랭식 열교환기(ACHE) 헤더박스의 구조해석을 형상 입력부터 보고서까지 자동화하는 엔지니어링 소프트웨어입니다.

제품 문의

손으로 하던 해석 절차를 하나의 흐름으로

엔지니어가 요소망을 다듬고 하중조합을 하나씩 돌리던 작업을 자동화된 절차로 바꿉니다. 시간과 비용 때문에 생략하기 쉬운 하중조합까지 같은 절차로 모두 계산합니다.

  1. 3D 모델링

    헤더박스와 노즐의 형상을 입력받아 해석용 3D 형상을 자동으로 만듭니다.

  2. 유한요소해석

    Python으로 해석 입력 파일을 만들고 CalculiX 솔버로 실행해 하중조합을 모두 계산합니다.

  3. 보고서 생성

    SCL(Stress Classification Line) 결과를 포함한 표준 양식의 해석 보고서를 작성합니다.

기본 하중조합 8가지

최대허용사용압력(MAWP)에 풍하중과 지진하중을 방향별로 조합한 8가지를 기본으로 계산합니다.

하중방향
MAWP + 풍하중+X, −X, +Y, −Y
MAWP + 지진하중+X, −X, +Y, −Y

제품 개요

여러 제작사의 도면을 검토하는 EPC 엔지니어링팀이 쓰기에 맞도록 만들고 있습니다.
